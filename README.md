# Trello Lite

Простая доска задач в духе Trello: колонки, карточки, цвета важности, перетаскивание.
Задачи хранятся в облаке (Supabase), а сама страница — на GitHub Pages.
Доска открывается с любого устройства по ссылке, даже когда основной компьютер выключен,
и изменения сразу появляются на всех открытых устройствах.

## Настройка (один раз, ~15 минут)

### 1. База данных в Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и нажмите **New project**.
   Придумайте пароль базы (он вам больше не понадобится, но сохраните его), регион — ближайший (например, Frankfurt).
2. Когда проект создастся: **SQL Editor → New query**, вставьте всё содержимое файла
   [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**. Должно появиться «Success».
3. Создайте свой аккаунт для входа в доску:
   **Authentication → Users → Add user → Create new user** — почта, пароль, галочка **Auto Confirm User**.
4. Запретите регистрацию посторонним:
   **Authentication → Sign In / Providers** → выключите **Allow new users to sign up** → Save.
5. Возьмите адрес и ключ проекта: **Project Settings → API Keys** (адрес — в **Data API**):
   - *Project URL* — вида `https://abcd1234.supabase.co`
   - *Publishable key* (или старый *anon public*)

   Впишите их в файл [`config.js`](config.js).
   ⚠️ Ключ **secret** / **service_role** никуда не вставляйте и никому не отправляйте.

### 2. Страница на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com), нажмите **New repository**,
   имя — например `trello-lite`, тип **Public**, **Create repository**.
2. На странице репозитория: **uploading an existing file** (или **Add file → Upload files**)
   и перетащите туда **все файлы и папки** из этой папки (`index.html`, `app.js`, `config.js`,
   `style.css`, `sw.js`, `manifest.webmanifest`, `icon.svg`, папки `vendor` и `supabase`) → **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты доска будет доступна по адресу `https://ВАШ-ЛОГИН.github.io/trello-lite/`.

Откройте эту ссылку на компьютере и на ноутбуке и войдите с почтой и паролем из шага 1.3.
Чтобы доска открывалась как отдельное приложение, нажмите в Chrome/Edge значок **«Установить»** в адресной строке.

## Как пользоваться

- **+ Добавить задачу** внизу колонки → введите название → Enter. Цветные кружки справа задают важность.
- **Перетаскивайте** карточки мышью между колонками и внутри колонки; колонки — за заголовок.
- **Клик по карточке** — окно задачи: название, описание, важность, перенос в другую колонку, удаление.
- **Двойной клик по названию колонки** — переименовать; **⋯** — меню колонки.
- **Фильтр** в шапке показывает только задачи нужной важности.
- Индикатор справа вверху: зелёный — всё синхронизировано, красный — нет интернета
  (тогда доска только для просмотра; связь и пропущенные изменения подтянутся сами).

Цвета важности: 🔴 Срочно · 🟠 Высокая · 🟡 Средняя · 🟢 Низкая · ⚪ Без важности.

## Полезно знать

- **Бесплатный проект Supabase засыпает**, если им не пользоваться неделю. Тогда доска не загрузится —
  зайдите на supabase.com в свой проект и нажмите **Restore project**. Данные при этом не теряются.
- **Обновить приложение** — загрузите изменённые файлы в репозиторий тем же способом (Upload files).
- **Резервная копия** — в Supabase: **Table Editor → cards / columns → Export → CSV**.
- Адрес страницы и ключ из `config.js` видны всем, кто откроет сайт, — это нормально:
  без вашей почты и пароля доску не прочитать и не изменить (это обеспечивают правила из `schema.sql`).
